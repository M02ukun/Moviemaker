# きりぬき帳

長い動画から好きな場面を探して切り抜き、1本につなげて書き出すスマホ向けのWebアプリです。

- 音声をすぐに分析して、熱量（声の大きさ・話す速さ）と静かな切れ目を表示します
- 端末内の文字起こし（Whisper / transformers.js）で、話の内容が変わった所で区間を分け、各区間に見出しを付けます
- 文字起こしは言葉で検索して、その場面に飛べます
- 選んだ区間をつないで MP4 に書き出します

処理はすべてブラウザの中で行い、動画や音声を外部に送りません。初回だけ文字起こしモデル（約80MB、高精度は約250MB）を Hugging Face からダウンロードします。

## 使える環境

Android の Chrome を想定しています（WebCodecs・MediaRecorder を使用。WebGPU があれば文字起こしが速くなります）。

## フォルダ

- `docs/` — アプリ本体（GitHub Pages でこのフォルダを公開）
- `artifact/` — 最初に claude.ai 上で作った1ファイル版（音声分析のみ）
